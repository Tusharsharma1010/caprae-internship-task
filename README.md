## 2. Business I Love: Zerodha

**What I Love About It:**
- Zerodha revolutionized retail investing in India with low-cost brokerage and a transparent platform.
- It grew without external funding and maintained profitability.
- The user experience, Kite dashboard, and educational content (Varsity) empower investors.

**How it Makes Money:**
- Brokerage on intraday and F&O trades.
- Subscription-based services like Zerodha Coin for mutual funds.
- Margin funding and API-based platforms (like Kite Connect).

**Data That Matters Most:**
- Trading volumes
- Number of active accounts
- Daily Average Revenue Traded (DART)
- API usage metrics
- Client acquisition cost

**How AI Can Help:**
- AI can assist in analyzing user behavior and suggesting personalized investment strategies.
- Chatbots can simplify support and explain financial terms.
- Fraud detection models can monitor unusual trading patterns.
- AI-powered sentiment analysis can track investor mood based on news.
